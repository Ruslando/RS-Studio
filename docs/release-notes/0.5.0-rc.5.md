Changes since v0.5.0-rc.4.

## Projects

- Projects remember the format they were saved in. A project saved by a newer version of RS Studio asks before you save it here, because this version may drop what it does not know. Charts from before this change open and save as always.
- A Rocksmith export with the Mac package is one zip holding the PC and Mac packages, not two downloads.

## Editor

- Tie a note to the next one, as EOF's Linknext does.
- Any hand position is allowed on any note; only positions outside the 4-fret window are flagged.
- A new song starts at A440.
- Pasted and drawn notes stay within the song's end.
- The start tempo flag moves freely, up to the next marker.
- Spectrogram channel, view and reassignment can be bound to keys.
- Pausing no longer jumps back to the playhead.
- Note names, finger positions and effects show at a much lower zoom, and a bigger label size no longer needs more of it. A label is never shrunk; it is left out when its note is too narrow.
- Layer buttons that are on (hidden, locked, muted, solo) stand out from their row, also while you hover it.

## Fretboard and fingering

- Grips that need another hand than the saved anchor are offered.
- An older project keeps its kept position when its override has lapsed.
- The hand positions outside the 4-fret window are readable in light mode.

## Window and settings

- The window opens centred and fits the screen; the start card scales with it.
- A new interface scale slider zooms the whole window.
- The Appearance previews are plain skeletons of the editor, including its title bar, and no longer flicker.

This is a pre-release distributed through the Preview update channel.
