Changes since v0.5.0-rc.1.

## Chords, fingering and fretboard

- Chords are named from their notes and can be renamed on the stage and fretboard.
- Choose individual fingers or a complete chord fingering, including thumb options and barres across unused strings. Open strings remain unassigned.
- Refined hand reach, chord alternatives and stretch warnings; bass hand positions span five frets.
- Voicing overrides offer local, guided and locked behavior. Capo and hand positions use value lists, and other layers are dimmed on the fretboard.
- Export the fretboard's hand positions and selected fingerings to Rocksmith.

## Rocksmith export and validation

- Live arrangement checks surface errors and warnings in the editor and artifacts sidebar, with explanations at the affected notes.
- Improved phrase-start anchors, slide and pull-off anchors, slide-out boundaries, bend points, muted chords and ignored notes.
- Corrected low tunings, the low-bass fix, song lead-in rules and sustain handling for vibrato and tremolo.
- Note tails end 1/32 of a measure before the next note on export.
- Choose the song preview clip and level both song and preview audio.
- Set scroll speed per note layer; the default is 1.3, matching DLC Builder.

## Reliability

- Refresh model availability and show supported compute options while preserving the selected detector.
- Start the Linux sound engine before the first interaction.
- Restore focus when popovers close and open fretboard artifact lists on click.
- Keep preview release versions aligned across source metadata, tags and installer packages.

This is a pre-release distributed through the Preview update channel.
